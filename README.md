## 💗 About

This project is a pastel-themed productivity app that combines a simple to-do list with a customizable Pomodoro timer. I created this project to strengthen my JavaScript skills while building something practical that I could actually use during study sessions.

## ✨ Features

- Add, remove, clear all, and mark completion functions for tasks in a to-do list

- Customizable work & break sessions

- Automatically saves tasks using Local Storage

- Start, stop, and reset timer with click and alarm audio

- Cute pastel interface with interactive cursor changes (for fun!)

- Responsive layout
